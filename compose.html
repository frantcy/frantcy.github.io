令牌只保存在你这台手机的浏览器里，不会上传给任何人。建议用 fine-grained token，只勾这一个仓库的 Contents: Read and write。
怎么拿到这个令牌？
  1. 打开 github.com → 右上角头像 → Settings
  2. Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token，Repository access 选 Only select repositories → 选 frantcy/frantcy.github.io
  4. Permissions → Contents: Read and write，然后生成并复制
  5. 粘贴到上面输入框，点保存令牌
